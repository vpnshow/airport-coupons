<a id="how-to-use-airport-coupons"></a>

## 机场优惠码怎么用？

1. 先查看适用条件，确认新用户、首次购买、付款周期和套餐限制。
2. 复制对应的优惠码，在对应官网选好套餐后，将优惠码粘贴到结算页。
3. 确认折扣已生效，再核对付款总额与流量重置规则；年付折算月价不等于单月付款金额。

有付款周期限制的优惠码，需核对所选套餐是否满足条件；[微风网络](https://eoht.net/serve/airport/breeze)的 `weifeng90` 对应 **7 折**。[可信云](https://eoht.net/serve/airport/kexin)的 `kxy80` 暂无明确折扣数字，输入后以结算页显示的优惠为准。

<a id="airport-coupon-faq"></a>

## 机场优惠码常见问题

<a id="coupon-period-discount-stacking"></a>

### 优惠码能与年付、两年付等周期折扣叠加吗？

是否叠加需查看对应机场的结算结果，不能仅凭两项折扣分别存在就直接相乘。[星岛梦](https://eoht.net/serve/airport/xdm)和[飞猫云](https://eoht.net/serve/airport/flycat)均另列周期优惠，实际可用优惠码、叠加方式与付款总额应在选定套餐后确认。

<a id="coupon-annual-mini-plan-limits"></a>

### 年付小包都能使用优惠码吗？

各机场规则不同。[Sogo云](https://eoht.net/serve/airport/sogo)排除月付小包与年付小包；[星岛梦](https://eoht.net/serve/airport/xdm)的双十一活动码 `2happy80`、`2happy85`，以及[二猫云](https://eoht.net/serve/airport/2mao)、[灵猫](https://eoht.net/serve/airport/spiritcat)的对应优惠也不支持年付小包。[有一说一](https://eoht.net/serve/airport/u1s1)与[飞为](https://eoht.net/serve/airport/firefly)排除 ¥96 年包，[神行云](https://eoht.net/serve/airport/shenxing)排除年付特惠，[唯兔云](https://eoht.net/serve/airport/weitu)排除公告所称 79 年付包，[无忧链接](https://eoht.net/serve/airport/wuyou)的 MINI 链接年付 ¥79 套餐也不支持对应优惠码。请按所选套餐核对对应优惠的条件。

<a id="coupon-renewal-upgrade-rules"></a>

### 新人优惠码可以用于续费或升级吗？

先区分“新用户”“新客首单”和“全场套餐”等适用条件，不能把新人优惠直接套用到续费。[速界](https://eoht.net/serve/airport/sujie)分别提供新客 `sujie888` 与老顾客充值码 `xf888`，两者均为 8 折，但适用场景不同。[微风网络](https://eoht.net/serve/airport/breeze)明确支持新老用户新购、续费及升级；其他机场按对应优惠的条件与结算页说明选择。

继续比较套餐，可查看[机场卡片汇总](https://github.com/vpnshow/airport-cards)或[机场评测与套餐汇总](https://github.com/vpnshow/airport-summary)。
